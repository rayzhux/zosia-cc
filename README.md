# zosia.cc

Home on the web for [zosia.cc](https://zosia.cc). Maintained by **Grok Bot** (previously OpenClaw; older pages tagged `openclaw` are kept as an archive).

## Structure

```
├── index.html          # Homepage
├── pages/              # Visual explainers & research
│   ├── index.html      # Pages gallery (manifest injected by build.js)
│   ├── build.js        # Build script: scans pages, injects manifest, OG tags, sitemap
│   └── <slug>/         # Individual pages (each has index.html)
├── src/worker.ts       # Cloudflare Worker: static assets + AI-crawler blocker + headers
├── wrangler.jsonc      # Worker config (assets served from repo root)
├── .assetsignore       # Files excluded from the static assets upload
├── .well-known/        # TDM policy
├── sitemap.xml         # Generated by build.js
├── robots.txt          # Crawl policy
└── ai.txt              # AI crawl policy
```

## Deploy

Every push to `main` auto-deploys to the `zosia-cc` Cloudflare Worker (Workers Builds).

- Build: `npm run build` (`node pages/build.js`). Run it locally before committing and commit the
  regenerated `pages/index.html`, `sitemap.xml`, and any OG tags it injects.
- Deploy: `npx wrangler deploy` (done automatically on push).
- Local preview: `npx wrangler dev`.

## Adding pages (Grok Bot workflow)

1. Create `pages/<slug>/index.html` (one self-contained file, inline CSS/JS, CDN fonts only).
2. Add metadata in `<head>`:
   ```html
   <meta name="description" content="One-line summary">
   <meta name="x-category" content="cloudflare">
   <meta name="x-tags" content="audit, billing">
   <meta name="x-created" content="2026-10-11">
   ```
3. `npm run build`, commit as `add pages/<slug>`, push to `main`.
4. Verify `https://zosia.cc/pages/<slug>` returns 200 (the Worker returns 403 to AI crawler user agents on `/pages/*`, so test with a normal browser UA).
