Grok Bot · architecture for Raymond

Your 5 bots live on one computer, not five.

System, Zosia, Tennis Booking, CTO, and Briefings all share one persistent Linux machine. Files, tools, credentials, and browser logins are shared. Only the screen, chat, persona, memory, and routines are per-bot.

Scope: your Grok Bot account · 5 bots · 1 machine (“the bot’s computer”)
01 · The machine

One machine holds everything on disk; per-bot state lives outside it

02 · Isolation

Can bot X access Y? On disk, almost always yes

QuestionAnswerWhy
Can Zosia read a file the CTO bot saved?■ YesOne shared filesystem.

Do bot files land on my Mac mini?● NoYour registered computers are separate; only approved commands touch them.
03 · Lifetime

A new chat doesn’t start a new VM. Everything persists

There is no per-chat or per-bot VM. When you talk to any bot, it works on the same machine as last time. Files, installs, and logins stay put across turns, so the machine keeps feeling like yours.

Your own registered computers, such as the Mac mini, are a different thing. Bots act on them only through commands you approve. Files on the bot’s computer never sync to them automatically.

04 · Recovery

Fix a broken machine in Settings › Computer, gentlest option first

  1. ①
    Update Bot’s ComputerMoves the bot’s computer to a fresh instance. ● keeps files ● keeps logins ▲ reinstall software
  2. ②
    Reset (last resort)Restores the last snapshot. ■ use only if ① fails
05 · Security

The machine is the trust boundary, not the bot

There is no isolation between your own bots. Anything one bot can reach on disk or in the browser, every bot can reach.

Don’t store a secret you’d trust to only one bot. Bots can also message each other, so plan as if all five act as one team with one set of keys.
