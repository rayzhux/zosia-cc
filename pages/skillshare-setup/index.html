THE CONCEPT

What is Skillshare?

A single Go binary that keeps AI agent skills in sync. You write a skill once in one place — it appears in every tool via symlinks. Edit the source → all targets update instantly.

Source

One directory holds all shared skills. This is the single source of truth. On your machine: ~/.config/skillshare/skills/

Targets

Each AI tool's skills directory. Skillshare creates symlinks pointing back to the source. Edit once, update everywhere.

Sync

One command: skillshare sync. Links skills to all targets. Merge mode preserves existing local skills.

HOW TO SET UP

Step-by-Step Setup

M2 is already done. Here's the full picture for both machines.

1

M2 — Create a GitHub repo M2

Push your skillshare source to a private repo. This becomes the cross-machine sync channel.

# On M2 cd ~/.config/skillshare/skills git remote add origin git@github.com:glowright/.agents.git skillshare push -m "initial skills"
2

M4 — Install & connect M4

Install skillshare, init with "start fresh", add the git remote, pull.

# On M4 brew install skillshare skillshare init # choose [3] start fresh cd ~/.config/skillshare/skills git remote add origin git@github.com:glowright/.agents.git skillshare pull # pulls + syncs to all targets
3

M4 — Add targets M4

Register each tool's skills directory as a sync target.

skillshare target add claude ~/.claude/skills skillshare target add codex ~/.codex/skills skillshare target add cursor ~/.cursor/skills skillshare target add gemini ~/.gemini/skills skillshare sync
4

Daily workflow BOTH

Edit skills in the source, sync locally, push/pull across machines.

# Add or edit a skill vim ~/.config/skillshare/skills/my-skill/SKILL.md # Sync to local targets skillshare sync # Push to other machine skillshare push -m "updated my-skill" # On the other machine skillshare pull

WEB DASHBOARD

The Web UI

Run skillshare ui on either machine. Opens at http://127.0.0.1:19420 — local only.

Dashboard

Overview cards: skill count, targets, sync mode. Quick "Run Check" and "Run Scan" buttons.

Skills Browser

Visual cards for each skill. Filter by All / Tracked / GitHub / Local. View content inline.

Targets

See all targets with sync status, mode dropdowns (merge/symlink/copy). Add or remove targets.

Security Audit

Scans skills for prompt injection, data exfiltration, suspicious patterns. Block threshold configurable.

Git Sync

Push/pull directly from the UI. See commit history and remote status.

TUI Alternative

Prefer terminal? skillshare tui gives an interactive terminal UI with the same features.

Key insight: symlinks are bidirectional.

When you edit a skill directly in ~/.claude/skills/my-skill/, you're actually editing the source file (because it's a symlink). The change is immediately visible in Codex, Cursor, Gemini — no sync needed. skillshare push is only for syncing to the other machine.
