Context Window

This is the key architectural win. Argus runs on GPT-5.4 with 5× the context of Opus. Long pipeline scripts, massive JSON outputs from Reddit/X collection, multi-step synthesis — all fit comfortably. Zosia on Opus keeps the deeper reasoning for interactive work where it matters.

Mental Model — How to Use Discord

The simple rule

You talk to Zosia. You read Argus's output.
Argus posts to channels on schedule. Zosia is who you DM and @ in channels. They never talk to each other — Discord channels are the handoff.
Argus runs pipeline at 5:30am
→
Discord #reddit-gcc CV2 card posted
→
You ask Zosia "what did Reddit find today?"
→
Zosia reads channel adds her own take

When you want Argus to do something

Don't message Argus directly. He has no channel bindings — he can't hear you. Instead, tell Zosia: "re-run the Reddit pipeline" or "trigger the daily brief now". Zosia uses cron run --jobId to kick Argus's jobs on demand.
Argus cron jobs are the only way to invoke Argus. Each job is a self-contained instruction. Zosia manages them (create, update, disable, trigger) via her cron tool. Argus doesn't have the cron tool — he can't modify his own schedule.
If a pipeline breaks overnight, Argus posts an error card to the relevant channel. When you wake up and see it, ask Zosia to investigate — she'll read the error, check logs, fix the script, and re-trigger.

Rollback

Any job → cron update --jobId X --agentId main and it's back on Zosia. One command. No config change needed.
