Architecture

How They Work Under the Hood

last30days — Research Pipeline

  • Query expansion: Two-pass with tag-based domain bridging
  • Parallel fetch: Up to 10 sources simultaneously via Python async
  • Scoring engine: Bidirectional text similarity + engagement velocity + source authority + cross-platform convergence (trigram-token Jaccard)
  • Dedup: Fuzzy matching across platforms to merge identical stories
  • Synthesis: LLM writes grounded narrative from scored, ranked results
  • Persistence: SQLite for watchlist accumulation across runs

opencli — Dual Engine

  • YAML pipeline: Declarative adapters for simple data extraction (no code)
  • TS runtime: Browser injection for complex auth (bearer, CSRF, webpack)
  • Chrome Extension: Bridge daemon connects CLI to real browser via CDP
  • Electron control: CDP + AppleScript for desktop apps (Cursor, ChatGPT, etc.)
  • CLI Hub: Registry + auto-install for external tools (gh, docker, vercel)
  • Zero LLM cost: Deterministic adapters — 10K runs cost nothing

bb-browser — Browser-as-API

  • Core insight: Instead of scraping, run JS inside the user's real browser tab
  • Adapter tiers: Cookie fetch (1 min) → Bearer+CSRF (3 min) → Webpack injection (10 min)
  • Architecture: CLI → HTTP → Daemon → CDP WebSocket → Chrome
  • MCP mode: Direct stdio integration for Claude Code, Cursor
  • Tab-level: Per-tab event cache (network, console, errors) for debugging
  • Community adapters: One JS file per command in bb-sites repo

twitter-cli — Deep Platform Access

  • GraphQL reverse-engineering: Uses Twitter's internal API endpoints directly
  • curl_cffi: TLS fingerprint impersonation matching Chrome version
  • Full cookie forwarding: All browser cookies, not just auth_token + ct0
  • x-client-transaction-id: Generated header for request legitimacy
  • Self-healing: Live queryId fallback when GraphQL endpoints rotate
  • Rate limit aware: Configurable delays, exponential backoff, proxy support

Bottom Line — What Should You Care About?

These four tools operate at three different layers of the stack:

Layer 1 — Platform-specific access (twitter-cli): Deep, rich, write-capable access to one platform. Best-in-class for X/Twitter. The jackwener ecosystem also has xiaohongshu-cli, bilibili-cli, discord-cli, tg-cli.

Layer 2 — Universal access (opencli, bb-browser): Turn the entire web into a CLI. opencli is more ambitious (websites + Electron + CLI hub) but younger (3 weeks old, 10.8K stars already — explosive growth). bb-browser is more mature and philosophically elegant (your browser IS the API).

Layer 3 — Intelligence (last30days): Doesn't just fetch data — it thinks about it. Cross-platform convergence detection, scoring, narrative synthesis. The research agent, not the data pipe.
