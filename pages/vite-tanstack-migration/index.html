The Great Unbundling

The web dev ecosystem is fracturing away from monolithic meta-frameworks. Vite won the build layer. TanStack is winning routing. Void Cloud is gunning for the deploy layer. Here's what it all means for zosia.cc — and what the migration looks like.

2 The Players — Who Are They?
Build Tool

Vite

Created by Evan You (Vue creator). The frontend build tool that replaced Webpack. Instant hot module reload, esbuild in dev, Rollup in prod. React, Vue, Svelte, Solid — everyone uses Vite now.

De facto standard

Testing

Vitest

Test runner built on Vite. Same config, same plugin pipeline, same transform layer. Replaced Jest for Vite projects. Native ESM, no config duplication, shares the dep resolution.

Vite-native

Routing

TanStack Router

By Tanner Linsley (TanStack Query fame). Type-safe file-based routing for React. No magic — explicit loaders, search params as first-class, full TypeScript inference. The anti-Next.js router.

Rising fast

Full-Stack Framework

TanStack Start

TanStack's full-stack framework. Vite under the hood, TanStack Router for routing, TanStack Query for data fetching. Server functions, SSR, explicit boundaries. The composable alternative to Next.js.

The challenger

Toolchain Company

VoidZero

Evan You's company. Building the unified JS toolchain in Rust: Rolldown (replaces esbuild + Rollup inside Vite), Oxc (replaces Babel, ESLint internals). Owns the entire compile pipeline.

$46M funded

Deploy Platform

Void Cloud

VoidZero's Vercel competitor. void deploy — one command gets you DB, KV, storage, queues, cron, auth, AI inference. Built on Cloudflare's edge. Framework-agnostic. Just launched March 2026.

Brand new

4 Who's Already Moving?

This isn't theoretical. Major projects and companies are actively migrating. The TanStack + Vite stack is gaining adoption fast — even Anthropic's own developer templates use it.

Anthropic / Claude

Netlify's official Claude AI template is built with TanStack Router + Vite (migrated from Vinxi to Vite 7+). Their Claude chat starter uses TanStack Query + Zustand for state. It's the recommended way to build Claude-powered apps.

SaaS Teams Migrating

BeyondIT published detailed benchmarks after moving a production SaaS from Next.js 16 to TanStack Start. Results: 5x faster dev startup, 2.5x faster HMR, and resolved persistent memory leaks that caused OOMKilled pods.

Netlify Backing TanStack

Netlify's official template library now features TanStack Start as a first-class starter. They're betting on the composable stack as the alternative to Vercel's Next.js lock-in.

Cloudflare Partnership

Void Cloud is built entirely on Cloudflare's network. Workers, KV, R2, D1, Queues — Cloudflare provides the infrastructure, VoidZero provides the DX layer. Strategic alignment against AWS-backed Vercel.

Community Momentum

"Goodbye Vercel?" articles trending on Medium (March 2026). Developer sentiment shifting from "Next.js is the default" to "do I actually need all this complexity?"

Void Cloud Risk

Launched days ago. No production track record. The tech is sound (Cloudflare infra underneath), but the DX layer is brand new. Migration stories don't exist yet. Wait 3-6 months before betting production on it.

Cloudflare Pages: The Safe Bet

You already pay for Cloudflare. CF Pages serves static sites with unlimited bandwidth on the same edge network Void Cloud uses. Plus you get CF Access for auth (the exact UX we discussed — Google login for you, email OTP for friends).

7 Migration Plan for zosia.cc

The Good News: This is a 30-Minute Migration

zosia.cc is static HTML. No framework to escape. The migration is literally "point Cloudflare Pages at the same GitHub repo instead of Vercel." Here's the plan:

Phase 1 — Now

Move to CF Pages

  • Connect rayzhux/zosia-cc to CF Pages
  • Point a subdomain (e.g., pages.zosia.cc) at it
  • Add CF Access for authentication
  • Update share.sh to use new URL
  • Keep Vercel running in parallel until verified

30 min

Phase 2 — When Needed

Add Interactivity

  • If zosia.cc needs dynamic features (search, filtering, live data)
  • Add Vite + TanStack Router for an SPA shell
  • Keep existing HTML pages as content
  • Use CF Workers for any API endpoints
  • This is optional — only if static isn't enough

If needed

Phase 3 — Future

Evaluate Void Cloud

  • Watch Void Cloud mature (3-6 months)
  • If they nail the DX, migration from CF Pages → Void is trivial (same infra)
  • void deploy would replace wrangler pages deploy
  • Gets you built-in auth, DB, cron for free
  • Low-risk: same Cloudflare network underneath

Watch

What about WAG (worldauto.group)? That's a separate question. If WAG uses Next.js with SSR/ISR features, keep it on Vercel — the migration cost isn't worth it. If it's mostly static, same story as zosia.cc: move to CF Pages. Check the actual stack first before deciding.
8 The Verdict

Bottom Line

The web dev world is unbundling. Vite won the build layer. TanStack is winning routing + data. Cloudflare is winning the edge. Vercel's moat (Next.js lock-in) is shrinking as every alternative gets better.

For zosia.cc specifically: move to Cloudflare Pages now. It's free, you already pay for CF, you get auth (CF Access) that Vercel charges $20/mo for, and unlimited bandwidth. The migration takes 30 minutes because there's nothing framework-specific to rewrite.

For new projects: Vite + TanStack Start on Cloudflare Workers is the stack to bet on in 2026. Keep Void Cloud on your radar — when it matures, it'll be the vercel deploy equivalent for the post-Vercel world.

For existing Next.js apps: don't migrate unless you're hitting the pain points (memory leaks, cache debugging, slow dev server). The ecosystem advantage is still real.
