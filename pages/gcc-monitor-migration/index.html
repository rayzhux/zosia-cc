What last30days Brings to the Table

✅ What We Gain

  • 10+ sources in one tool: Reddit (with comments via ScrapeCreators), X/Twitter, YouTube transcripts, HN, TikTok, Instagram, Polymarket, Bluesky, Truth Social, web search
  • Built-in watchlist: SQLite persistence, watchlist.py add/remove/run-all, budget guards ($5/day default)
  • Delta intelligence: "What's new since last run" — engagement spikes, new voices, gone-quiet detection
  • Cross-platform scoring: Engagement velocity × text similarity × source convergence
  • Comparison mode: "X vs Y" auto-runs 3 parallel research passes
  • Zero maintenance: Community-maintained (17.4K stars), regular updates
  • YouTube + video insights: Transcripts from yt-dlp add a dimension we completely lack today

⚠️ What We Lose

  • GCC-specific theme engine: Our custom BUILDING → RECURRING → FADING lifecycle tracking
  • 29-subreddit precision: last30days searches by topic, not by specific subreddit list — we lose granular sub-by-sub coverage
  • Arabic-language queries: Our X monitor has 8 Arabic queries + Arabic engagement filters — last30days is English-first
  • 40+ tracked GCC accounts: Specific account monitoring (DXBMediaOffice, DIFC, MISA etc.) won't directly translate
  • Historical SQLite continuity: reddit_gcc.db has months of classified posts; migration means fresh start
  • Cron-native operation: last30days is designed for interactive use; watchlist/cron integration exists but is less battle-tested than our Argus pipeline

Recommendation

Proposed Migration Strategy: Hybrid Approach

A straight replacement loses too much GCC-specific depth. Instead, I recommend a hybrid approach: use last30days as the multi-source research engine, but wrap it in a thin GCC-aware orchestrator that preserves our domain knowledge.

🧠 Option A: Full Replace

Kill both monitors, use last30days watchlist with GCC topics.

  • Fastest to implement (1-2 hours)
  • Lose Arabic queries, account tracking, subreddit precision
  • ~70% cost reduction
  • Risk: GCC-specific signals get diluted by global noise

Medium Risk

🎯 Option B: Hybrid (Recommended)

last30days as engine + thin GCC wrapper for domain focus.

  • Install last30days as OpenClaw skill
  • Write a GCC wrapper script (~200 lines) that runs targeted searches
  • Preserve our 6 GCC query categories + Arabic queries via custom search terms
  • Add YouTube + HN + TikTok as bonus sources (free uplift)
  • Keep Argus cron delivery to #intel
  • Cost: ~$20-30/mo (ScrapeCreators + minimal LLM)

Best Balance

🔬 Option C: Parallel Run

Run last30days alongside existing monitors for 2 weeks, compare.

  • Zero risk — existing monitors keep running
  • Compare signal quality side-by-side
  • Higher cost during parallel period (~$116/mo)
  • Best data-driven decision after 2-week eval

Phase 1 — Day 1 (2-3 hours)

Install & Configure last30days

• Install via ClawHub: clawhub install last30days
• Configure ~/.config/last30days/.env with: X cookies (FROM_BROWSER=auto), SCRAPECREATORS_API_KEY (need to sign up — 100 free calls), yt-dlp already installed
• We already have: EXA_API_KEY, OPENAI_API_KEY, BRAVE_API_KEY
• Run test: python3 last30days.py "Dubai startup investment" --emit=json
• Validate all 10+ sources fire correctly

Phase 2 — Day 1-2 (3-4 hours)

Build GCC Monitoring Wrapper

• Create skills/gcc-monitor/ — thin orchestrator around last30days
• Map our 6 query categories to last30days search terms:
  → high_signal_en: "Dubai UAE startup tech business investment"
  → high_signal_ar: "دبي الإمارات استثمار تقنية ريادة"
  → industry_verticals: "electric vehicle real estate automotive GCC"
  → pain_points: "Dubai overpriced scam worst service complaint"
  → macro_signals: "UAE regulation IPO golden visa corporate tax"
  → discovery: broad high-engagement GCC content
• Use watchlist.py to register 6 GCC topics with custom search queries
• Build Discord CV2 delivery adapter (format last30days JSON → #intel card)
• Add Arabic query pass using --search reddit,x flag

Phase 3 — Day 3-7 (passive)

Parallel Validation

My Take

Go with Option B (Hybrid). last30days is a genuine upgrade in breadth — 10+ sources vs our 2, YouTube transcripts and HN are real signal additions for GCC business intel, and the cost drops ~70%.

But a straight replacement is wrong. Our 29 subreddits, Arabic queries, and 40+ tracked accounts represent months of curation. The thin wrapper preserves that domain knowledge while leveraging last30days as the engine.

The watchlist + run-all + budget guard pattern is exactly what we need for cron operation. We just need a ~200-line adapter to map our GCC queries and format output for Discord delivery.

Timeline: One weekend to build and validate. Run parallel for a week, then cut over. By mid-April, both custom monitors retired, $66/mo saved, and we're getting YouTube + HN + TikTok signals we never had.
