选购要点

买之前需要知道的

Linux 兼容性黄金法则：AMD Ryzen + Radeon iGPU 是最省心的选择 — 开源驱动（amdgpu / Mesa）在 Ubuntu/Debian 上开箱即用。Intel Core Ultra + Arc 也不错，但偶尔需要更新 kernel 或固件。NPU 加速（Ryzen AI、Intel NPU）在 Linux 下大多需要额外 SDK/驱动，不是完全开箱即用。
💾 内存与存储扩展建议
  • 内存：跑容器/VM 建议至少 32GB；本地 AI 推理（7B–13B 量化模型）建议 64GB。优先选 2× SO-DIMM 插槽的型号，避免焊死内存
  • 存储：双 M.2 NVMe 是理想配置 — 一块给系统/swap，一块给数据/模型权重。GMKtec K12 甚至有 3 个 M.2 插槽
  • NAS 向：ZimaBoard / ZimaBlade 带 SATA 接口，适合 2.5"或 3.5" 机械盘扩展
  • Oculink 接口：GMKtec K12 带 Oculink，可外接显卡坞（eGPU），是低价格接近独显性能的巧妙方案
🔊 功耗与噪音参考
  • 超静音：N100/N150 系列 idle ~10W，近乎无声（~30dB），适合放卧室或桌面
  • 中端 Ryzen：Minisforum UM870 等 idle ~15W，满载 ~60W，风扇可感知但不扰人
  • 高性能 H 系列：GEEKOM GT15/A9 等 idle ~30W，满载 ~100W，噪音明显（~40–43dB）
  • 独显工作站：Minisforum MS-02 Ultra idle ~65W，满载可超 200W，噪音较大，需要通风
  • 无风扇方案：MeLE Quieter4C N150 — 完全无声，适合 24/7 轻量服务，但性能有限
🐧 Linux 发行版兼容性笔记
  • AMD Ryzen + Radeon iGPU：Ubuntu 22.04/24.04、Debian 12、Arch 均无需额外配置，主流开箱即用
  • Intel Core Ultra + Arc GPU：需要 kernel 6.2+（Arc 显卡），部分 Wi-Fi 6E 固件需手动安装，整体稳定
  • System76 Meerkat：厂商专属 firmware-manager、system76-driver、power 工具，Pop!_OS 体验最完整，Ubuntu 也支持
  • TUXEDO Nano Pro：TUXEDO Control Center 提供风扇曲线、功耗模式管理，TUXEDO OS 基于 Ubuntu，也可装标准 Ubuntu
  • Jetson Orin：NVIDIA JetPack SDK（基于 Ubuntu），专为 CUDA 推理优化，不适合通用 Linux server 用途
  • NPU（Ryzen AI / Intel NPU）：大多需要厂商 SDK（ONNX Runtime EP、OpenVINO、ROCm），不是标准 Linux 开箱支持
🔬 AI 推理性能实际预期
  • TOPS 数字是厂商宣称值，参考意义有限。实际吞吐取决于模型大小、量化精度（FP32/FP16/INT8/INT4）、框架优化（llama.cpp、ONNX Runtime、TensorRT）和持续散热
  • iGPU 推理：Radeon 780M/890M 或 Intel Arc iGPU 在 llama.cpp（Vulkan/ROCm backend）上跑 Q4 量化 7B 模型速度约 15–30 tokens/s，够用
  • NPU 推理：目前 NPU 在 Linux 下支持最好的是 OpenVINO（Intel）和 AMD ROCm 的有限支持，对 llama.cpp 等通用框架的原生 NPU 加速仍在早期阶段
  • 内存带宽是瓶颈：LLM 推理是内存带宽密集型任务。iGPU 共享系统内存，DDR5 的带宽对速度影响显著 — 选 DDR5 配置优于 DDR4
🏘️ Homelab 社区热门选择
  • 翻新 Dell OptiPlex Micro / HP EliteDesk Mini：Reddit homelab 社区最常推荐的廉价入口，$100–300，驱动成熟，企业 vPro 远程管理，缺点是型号老
  • Minisforum UM 系列：UM690/UM870 是国内用户和 homelab 玩家最喜欢的 AMD mini PC，BIOS 解锁友好，双 NVMe，跑 Proxmox / TrueNAS 有大量教程
  • Beelink SER 系列：Amazon 上评价很高，价格相对友好，社区用于 Docker 集群和轻量虚拟化
  • ASRock DeskMini A300：支持桌面级 AM4 CPU（可上 Ryzen 9），扩展性强，但比较旧了，新购性价比不高
