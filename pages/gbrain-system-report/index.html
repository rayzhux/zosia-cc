routing rules

When to reach for which tool.

The skill encodes this — but it's worth seeing visually. Different shapes of question want different tools.

open / fuzzy recall

"What did we decide about the F&I anchor partners?"

query

Hybrid RAG with multi-query expansion. Default detail=medium; drop to low when you only need the compiled truth.

known topic name

"Find every page that mentions World Automotive Group."

search

Full-text. Faster and more predictable than query when you already know the exact term.

known slug

"Read companies/axxion."

get_page

Returns frontmatter + compiled truth + timeline as one structured payload.

fuzzy slug

"Is it cheng-hao or hao-cheng?"

resolve_slugs

Saves a wasted 404 from get_page. Returns top fuzzy matches.

expand a known page

"Who points at Dhow Holding?"

get_backlinks

Inbound edges with link_type and context — much cheaper than traverse_graph.

typed-edge questions

"Who has Raymond invested in?"

traverse_graph link_type=invested_in

Filtered traversal stays small. Avoid direction=both, depth=2 on hubs.

enumerate by source

"List the most-recently-updated person pages."

list_pages

Filterable by type, tag, limit. Sorted by updated_at desc.

find gaps

"Which pages have no inbound links?"

find_orphans

Returns large lists for big brains — paginate or filter by domain.

findings

What I noticed while testing.

Two of these need your eyes. The rest are healthy signals.

issue · attention

Autopilot lock is stuck.

Every autopilot-cycle for the past hour returned {status: "skipped", reason: "cycle_already_running"}. That includes 9 of the last 10 jobs. Real ingest/embed/extract isn't running — only git_sync from ~/brain is keeping data flowing. Could be a still-running cycle holding the lock, or stale state. Worth checking before more email/calendar volume piles up unprocessed.

gotcha · skill patched

traverse_graph blast radius.

traverse_graph(depth=2, direction="both") on companies/axxion returned 3.8M characters and overflowed the tool sandbox. Hub nodes (Raymond, Terence, Alex, Thomas, Khalid) will all do this. Patched the GBrain skill with a new "blast radius" section: default depth=1 on hubs, or filter by link_type, or use get_links / get_backlinks for adjacency without traversal.

healthy

Embed coverage is excellent.

98.3% of chunks embedded (23,958 of 24,371). Only 413 missing — within normal in-flight backlog for a brain this size. Brain score 92/100 is solid; biggest drag is link density (40%, scoring 25/40).

healthy

Native MCP works in fresh sessions.

Last session got wedged with ClosedResourceError on every gbrain MCP call. This session — fresh process, same wrapper — connected cleanly and ran 15 calls without a hiccup. The wedge was the in-session client's stale state, not GBrain. Skill already documents the right response: wait the backoff, don't restart the gateway.

tradeoff

2,321 orphan pages.

~32% of pages have no inbound wikilinks — mostly auto-imported daily emails (Microsoft 365 promo notifications, WAG meeting invites). Acceptable for an archive, but it's why link density score is low. If link density matters, an extract job would surface real entities inside those email bodies.

healthy

Version history is working.

people/raymond-zhu has 12 snapshots since 2026-04-23 — every git_sync produces a new version. Content has stayed stable; this is the safety net for any future write-rule loosening.

No silent writes. Period.

Three things to consider next.

action — soon

Unstick autopilot.

I'd like to inspect the running cycle (if any) before clearing the lock — could be a real long-running job, could be a leftover from a crash. Want me to pull list_jobs(status: "active") and trace from there?

decision — when comfortable

Loosen the write rule (eventually).

Once you trust the routing, the natural tier is: reversible appends (add_timeline_entry, add_link, add_tag) → just do, report after. put_page on new entities → still confirm. delete_page → always confirm. Skill is structured to flip when you say so.

enhancement — optional

Wire link extraction.

2,321 orphan pages is mostly auto-imported email content with real entities buried in the body. A scheduled extract job (built-in type) would lift link density from 40% → much higher and push the brain score north of 95.
