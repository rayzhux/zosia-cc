Remaining Gaps — Action Required

GAP 1: --light-context not on nightly security cron
v2.8 mandates --light-context (or equivalent) to prevent workspace files from being injected into the isolated audit session context. Without this, a compromised workspace file could theoretically influence the auditor's judgment. Need to check if OpenClaw supports this setting on cron jobs, then add it to b8752ee6.
PRIORITY: HIGH — architectural defense gap
GAP 2: DLP scan missing crypto-specific patterns
Our metric #11 catches API keys, PEM headers, and hardcoded passwords. The v2.8 reference script also scans for: Ethereum private keys (64 hex chars), BIP39 mnemonics (12/24 word sequences), WIF Bitcoin keys, and xprv extended keys. While we don't have crypto tooling, these patterns protect against accidental paste/exposure. Needs sudo to unlock audit script.
PRIORITY: MEDIUM — DLP completeness
GAP 3: No outbound connection monitoring in audit
Reference script counts established outbound connections (ss -tnp state established) and warns at >20. Our script only checks listening ports. Adding outbound connection count would catch data exfiltration or C2 beaconing. macOS equivalent: lsof -nP -iTCP -sTCP:ESTABLISHED.
PRIORITY: MEDIUM — detection coverage
MINOR: Token optimization — output truncation
Reference script uses head -n 16/20/50 to cap command outputs before logging. Our script pipes full lsof and ps output. Not a security gap but wastes tokens during LLM review.
PRIORITY: LOW — efficiency
