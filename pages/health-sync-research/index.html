Tools Worth Knowing

Health.md

★ 67 · Swift · MIT

Full iOS + macOS app. Exports to Markdown/JSON/CSV with frontmatter (Obsidian-compatible). Multipeer Connectivity for iPhone→Mac sync. Scheduled exports, menu bar widget, keyboard shortcuts. The most complete open-source option.

Multipeer Sync Obsidian Scheduled Menu Bar 50+ workout types

apple-health-mcp

★ 516 · TypeScript

MCP server for querying Apple Health data with natural language and SQL. Indexes XML exports into DuckDB. Works with Claude Desktop and other MCP clients. Perfect query layer on top of any export method.

MCP DuckDB Natural Language Claude Desktop

Open Wearables

★ 700 · Python/TS · MIT

Self-hosted platform unifying all wearable data (Apple, Garmin, Polar, Suunto, Samsung). Docker-based. REST API, developer portal, AI health assistant (coming). Overkill for just Apple Health, but future-proof if you ever add more devices.

Multi-device Docker REST API iOS SDK AI Assistant

Health Auto Export

★ 211 (docs repo) · App Store

Mature iOS app (150+ metrics). Background auto-export to iCloud, REST API, MQTT, Home Assistant. Premium tier adds Mac sync companion + background automation. Most popular paid option in the community — every Reddit thread mentions it.

Background Sync REST API MQTT iCloud Drive TCP Server

ai-health-sync-ios

★ 4 · Swift · Apache-2.0

iOS app + macOS CLI for peer-to-peer sync over TLS 1.3 with mutual cert auth. QR code pairing. Homebrew installable CLI (healthsync fetch --types steps). Very security-focused. Includes an OpenClaw skill.

TLS 1.3 QR Pairing Homebrew OpenClaw Skill

healthkit-to-sqlite

★ 8 · Rust

Converts Apple Health XML export → SQLite database. Records, Workouts, ActivitySummary. GeoJSON workout routes. Pairs with Datasette for instant web UI. Great for one-time historical imports.

SQLite Datasette Rust GeoJSON Routes

Why not iOS Shortcuts alone?

After deep research, Shortcuts has real limitations for this use case:

  • Limited HealthKit access — can only query a few metric types (steps, HR, sleep). No workouts, no HRV, no blood oxygen.
  • No true background execution — "Run Immediately" automations still require the phone to be unlocked and can silently skip.
  • No bulk historical data — each "Find Health Samples" action returns limited results.
  • Fragile — iOS updates frequently break Shortcuts automations, especially health-related ones.
  • Community consensus — Reddit r/QuantifiedSelf and r/shortcuts consistently recommend Health Auto Export or a native app over pure Shortcuts.

Shortcuts works as a trigger (e.g., "run after workout") but not as the primary export mechanism.
