1 What ClawChief Actually Is

Carson's repo is a complete "Chief of Staff in a box" — 4 skills, 3 workspace files, 5 cron templates, and a placeholder-based config system. Here's every component mapped.

📧 executive-assistant Adapt

The heavyweight. ~800 lines of instructions covering:

  • Inbox triage every 15 min (message-level Gmail search, not thread)
  • Auto-reply for low-risk ops email (scheduling acks, confirmations, vendor noise)
  • Follow-up cadence: 2 days → 5 days → 7 days → escalate
  • Calendar conflict checking across ALL calendars before booking
  • Booking link support (Calendly, HubSpot, Acuity, etc.)
  • Task list sync — reads tasks/current.md at start of every run
  • Sent-mail sweep for unanswered outbound threads
  • Reply templates for scheduling, follow-up, confirmations
  • Escalation rules: legal/financial/press/sensitive → ask owner

📊 business-development Defer

Carson's "first 10 customers" machine. Very opinionated:

  • Google Sheet as CRM (14-column outreach tracker)
  • Lead sourcing against target market/geography
  • Email + LinkedIn outreach as separate tracked actions
  • LinkedIn browser automation (agent-controlled profile)
  • Inbound reply processing → sheet + email in one workflow
  • Outreach templates in resources/partners.md

⚠️ Very specific to Carson's counselor/coach referral business. Needs total rewrite for Dhow.

✅ daily-task-manager Install

Single-file task system. Elegant and immediately useful:

  • tasks/current.md as canonical source of truth
  • Sections: Today, Every Weekday, Backlog (dated + undated), Recurring, Done
  • Zosia: ownership prefix for assistant-owned tasks
  • Heartbeat integration — reads file before check-ins
  • Deduplication rules, carry-forward logic, completion timestamps

🌅 daily-task-prep Install

Pre-dawn cron that quietly builds today's plan:

  • Pulls weekday recurring items into Today
  • Promotes due-today backlog items
  • Adds calendar meetings (owner-owned only)
  • Preserves manually added priorities
  • Weekend-aware (skips recurring on Sat/Sun)
  • Silent unless something needs attention

📋 workspace files Merge

  • HEARTBEAT.md — EA heartbeat with inbox check, calendar scan, task list reference, marketing nudges. More structured than ours.
  • TOOLS.md — Email conventions, outreach tracking, LinkedIn browser rules, Linear MCP, signature templates
  • tasks/current.md — Template task file with all sections

⏰ cron templates Adapt

  • EA Sweep: */15 8-21 * * * — every 15 min during work hours
  • Task Prep: 0 2 * * * — 2 AM local (pre-wake)
  • BizDev Sourcing: 0 2 * * * — find 10 new leads nightly
  • Nightly Backup: disabled by default
  • Self-Update: disabled by default

5 Decisions I Need From You

Before I start building, I need calls on these 5 items.

1. Email Autonomy Level

Carson's EA auto-replies to scheduling, confirmations, vendor noise, and routine admin without asking. That's the whole point.

My recommendation: Start with Carson's full autonomy level. Zosia already has the judgment — the skill just codifies when to act vs escalate. We can always tighten the leash if something goes wrong.

2. Which Inbox to Sweep?

Options: zosia.salt@gmail.com only, or also sweep Raymond's personal + work accounts.

My recommendation: Primary sweep on zosia.salt@gmail.com. Secondary read-only scan of your two accounts for calendar-relevant and scheduling threads only. I don't auto-reply from your accounts without escalation.

3. EA Sweep Frequency

Carson runs every 15 min. That's aggressive — it's a lot of cron fires (56/day) and token spend.

My recommendation: Start at every 30 min (*/30 8-21 * * *) = 28 fires/day. Tighten to 15 min later if you want faster response times.

4. Business Development Skill — Install or Defer?

Carson's bizdev skill is purpose-built for counselor/coach referral outreach in a specific geography. Total mismatch for Dhow.

My recommendation: Defer entirely. If/when you have an active outbound push, we'll build a Dhow-specific version from scratch. Don't install dead code.

5. Proactive Updates — Where?

Carson routes to Slack DM. We have: this #executive-assistant channel, Discord #briefings, WhatsApp, Telegram.

My recommendation: EA alerts to this Slack #executive-assistant channel (threaded). Urgent items also DM you on Slack. Keep Discord for system/agent ops, not EA.
