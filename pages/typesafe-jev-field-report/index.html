Jev is a semantic function.

TypeSafe AI’s first “System One” model turns messy text or JSON into bounded probabilistic decisions. The product thesis is real; the launch rhetoric is ahead of the production evidence.

Working definition
A cheap decision sidecar—not another coding model.

Keep Claude or Codex for reasoning and generation. Insert Jev where ordinary software repeatedly needs to choose, score, route, rank, or gate.

Product anatomy

One state. Many independent questions. Typed answers.

Jev evaluates a shared piece of text or JSON against bounded questions in parallel. Your code—not the model—sets thresholds, owns side effects, and decides when to escalate.

The architectural catchQuestions in one request share the state but cannot see one another’s answers. Batch independent judgments; use another call for dependent stages.
Ranked use cases

Deploy where the judgment is frequent, bounded, and reversible.

The sweet spot is a locally observable semantic decision with a known answer space and a credible human or model fallback.

High-volume triage and routing

Support tickets, inbound leads, documents, email, claims, moderation queues, and vehicle-service requests.

Why it fitsFixed labels, huge volume, low value per item, human fallback.

Retrieval and context firewall

Rank passages and flag irrelevant, contradictory, or instruction-bearing content before an agent consumes it.

Why it fitsParallel judgments reduce context cost; code can exclude flagged passages.

Agent task and skill routing

Choose a specialist, skill, workflow, or model tier from short candidate descriptions.

Why it fitsBounded and repeated; a Noul can ask whether any candidate is suitable.

PR and change triage

Classify change type, estimate blast radius, and decide whether expensive review is warranted.

Why it fitsStatic tools establish exact facts; Jev judges the semantic remainder.

Continuous evaluation

Check citations, relevance, policy fit, response quality, or bounded completion criteria on every run.

Why it fitsLow unit cost enables per-run checks; uncertain cases can escalate.

Semantic pre-action warning

Flag destructive, credential-touching, external, or out-of-scope agent actions.

Why it fitsA valuable second opinion—never the permission system itself.

Recommended first promptPlan before code
Use the TypeSafe skill. Inspect this repository and propose the three
highest-value places where Jev could replace fragile prompt-and-parse logic
or expensive repeated LLM judgments.

For each, show:
1. the exact state sent to Jev;
2. all Choice / Noul / Score questions in one batched request;
3. thresholds and the escalation path;
4. a labeled evaluation set and acceptance metric;
5. what remains deterministic code.

Do not implement yet. Do not use Jev for arithmetic, date comparison,
security enforcement, or open-ended generation.

Let Jev decide

  • Which bounded category fits?
  • How relevant is this passage?
  • Does this claim follow from evidence?
  • How much review is warranted?
  • Should an uncertain case escalate?

Keep out of Jev

  • Writing code, prose, plans, explanations
  • Arithmetic, dates, counts, exact parsing
  • Hard permissions and security boundaries
  • Executing tools or side effects
  • Multi-hop diagnosis and causal reasoning

The boundary discipline is the product discipline.

Privacy

No training on customer input

TypeSafe states it will not train or fine-tune models on inputs. Standard retention is not zero; enterprise ZDR is available by request.

Commercial

Managed proprietary service

SDKs and agent skill are MIT. The hosted model and API are proprietary; no public weights or self-hosting path were found.

Technical

Early-access surface

64k total request context, 32k state plus longest question, text-only input, and changing rate limits.

Recommendation

One advisory pilot. Two hundred labels. Then decide.

Start with Hermes skill routing or PR triage—measurable, reversible decisions that can save expensive model calls.

Build first

Hermes skill router

State: task plus compact skill descriptions. Choice: best skill. Noul: is any skill suitable? Auto-load only above a tuned threshold.

Measure: fewer incorrect and unnecessary skill loads without reducing completion quality.

Second pilot

Automotive case triage

State: normalized complaint plus service-history facts. Ask issue category, urgency, likely safety escalation, and evidence completeness.

Measure: routing accuracy, review time, and escalation calibration across English, Arabic, and Chinese.

Do not put Jev on every Claude/Codex tool call.The synchronous latency, privacy surface, and false confidence would swamp the benefit. Scope it to decisions that are both semantically fuzzy and economically frequent.
